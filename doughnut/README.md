# Torus Graph Embeddings

This project is an interactive explorer for graph embeddings on a torus (doughnut). It allows users to visualize how complex network structures can be mapped onto topological surfaces.

## 🚀 Features
- **3D Visualization**: Interactive torus model using Three.js and React Three Fiber.
- **Graph Projections**: Visualize vertices and edges mapped to the torus surface.
- **Topological Exploration**: See how the periodic boundaries of the torus affect connectivity.

## 🛠️ Built With
- **React 19**
- **TypeScript**
- **Vite**
- **Three.js** (+ `@react-three/fiber`, `@react-three/drei`)
- **Tailwind CSS**

## 💻 Local Development

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run dev server**:
   ```bash
   npm run dev
   ```

3. **Build for production**:
   ```bash
   npm run build
   ```
