Explorer Help

A guide to how the P3 explorer behaves.

Move Around

  • Click a tile in the control panel to add it to the canvas.
  • Drag a tile to move it. Nearby vertices snap together automatically.
  • Scroll to zoom in and out around the cursor.
  • Right-drag, middle-drag, or left-drag empty space to pan the canvas.
  • Double-click a tile or supertile to duplicate it with a small offset.

Select And Edit

  • Click a tile to select it. Shift-click for multi-select.
  • Ctrl + A selects all tiles.
  • Ctrl + D duplicates the current selection.
  • R rotates counterclockwise.
  • T rotates clockwise.
  • D or Delete deletes the tile.
  • Ctrl + Z or Cmd + Z undoes the last change. Ctrl + Y redoes it.

Matching Rule

Red outlines mark tiles involved in an invalid placement.

  • Shared vertices must have matching colours.
  • Shared edges with arrows must point in the same direction.
  • Tiles may not overlap.
  • Use the marking toggles to inspect vertices, arrows, and supertile borders.

Supertiles

  • Shift-click adds or removes tiles and groups from the current selection.
  • Select at least two tiles or supertiles, then press C to create a supertile.
  • New supertile definitions appear in the sidebar and can be spawned as tiles.
  • Placed supertiles keep a dashed magenta outer border when borders are visible.

Save And Export

  • Ctrl + S save tiling as `.json`.
  • Ctrl + L load a `.json` tiling from disk.
  • Ctrl + E open export — download as `.tikz`, `.pdf`, or `.svg`.
  • Built-in examples can be loaded from the example picker.
  • C create supertile from 2+ selected tiles.
